About the Project

The Space Mission Dashboard is a full-stack web application designed to provide users with comprehensive information about space missions. From historical Apollo missions to current SpaceX launches, users can explore mission details, crew information, and stay updated with the latest space news through integrated APIs.

The purpose of this project is to make space exploration accessible and engaging for everyone. Users can learn about the history of space travel, current missions, and future endeavors in a clean, professional interface that mimics mission control dashboards.

Key Features

Mission Data Display

Comprehensive display of mission information including name, agency, launch date, status, crew, and detailed descriptions.

Space News Integration

Real-time integration with space news APIs to keep users informed about the latest developments in space exploration.

Interactive UI

Modern, responsive interface with smooth animations and hover effects for an engaging user experience.

API Integration

Seamless communication between React frontend and Django REST API backend for efficient data retrieval.

Responsive Dashboard

Fully responsive design that works perfectly on desktop, tablet, and mobile devices.

Version Control

Properly managed with Git and hosted on GitHub for easy collaboration and deployment.

How to Run Locally

  1. Clone the repository: git clone https://github.com/yourusername/space-dashboard.git
  2. Navigate to the project directory: cd space-dashboard
  3. Install backend dependencies: pip install -r requirements.txt
  4. Install frontend dependencies: cd frontend && npm install
  5. Run the Django backend: python manage.py runserver
  6. In a new terminal, run the React frontend: cd frontend && npm start
